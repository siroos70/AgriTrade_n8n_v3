# سامانه واسطه‌گری انجیر و انار — n8n نسخه ۱

این نسخه بر اساس معماری Workflowهای موجود در آرشیو Shayanode طراحی شده، اما برای کسب‌وکار واسطه‌گری خرید و فروش انجیر و انار بازطراحی شده است.

## هسته نسخه ۱
1. ثبت فروشنده
2. ثبت خریدار
3. ثبت عرضه
4. ثبت تقاضا
5. تطبیق عرضه و تقاضا
6. ثبت معامله
7. محاسبه و ثبت کمیسیون
8. گزارش روزانه
9. ربات تلگرام با منوی فارسی

## پایگاه داده
PostgreSQL در نظر گرفته شده و SQL کامل در `01_پایگاه_داده/schema.sql` قرار دارد.

## نصب
1. PostgreSQL بسازید.
2. فایل `schema.sql` را اجرا کنید.
3. در n8n یک Credential از نوع PostgreSQL بسازید و نام آن را می‌توانید `اتصال PostgreSQL` بگذارید.
4. Workflowهای JSON را Import کنید.
5. Credential هر Node PostgreSQL را به اتصال واقعی خود وصل کنید.
6. برای ربات تلگرام یک Bot Token بسازید و Credential را به Nodeهای Telegram وصل کنید.
7. ابتدا Workflowهای ثبت فروشنده/خریدار/عرضه/تقاضا را تست کنید.
8. سپس Workflow تطبیق را فعال کنید.
9. در مرحله بعد Telegram و گزارش‌ها را فعال کنید.

## نکته
فایل‌های این بسته Credential واقعی، Token، رمز عبور یا API Key ندارند. بنابراین پس از Import باید Credentialهای محیط خودتان را انتخاب کنید.

## وضعیت
نسخه ۱ = MVP زیرساختی. موتور تطبیق اولیه است و برای تصمیم‌گیری تجاری نهایی باید معیارهای قیمت، کیفیت، زمان، منطقه، هزینه حمل و شرایط پرداخت دقیقاً با مدل کسب‌وکار تعیین شوند.

## زبان
نام Workflowها، نام Nodeها، پیام‌های ربات و توضیحات عملیاتی فارسی هستند.


## پنل فارسی
پوشه `11_پنل_فارسی` شامل پنل RTL فارسی است. فرم‌های ثبت، داده را به Webhookهای n8n ارسال می‌کنند. مسیرهای Webhook از بخش تنظیمات قابل تغییر هستند.


## نسخه ۲ پنل فارسی
پوشه `12_پنل_فارسی_نسخه_۲` شامل پنل مدیریتی با فهرست، جستجو، داشبورد و Webhookهای خواندن PostgreSQL است.
