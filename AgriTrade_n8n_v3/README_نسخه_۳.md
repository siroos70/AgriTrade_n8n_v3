# AgriTrade n8n — نسخه ۳: فروش حرفه‌ای

این نسخه هسته واسطه‌گری انجیر و انار نسخه ۲ را حفظ کرده و محتوای عملی PDFهای فروش را به CRM و فرایند فروش تبدیل می‌کند.

### بخش‌های اضافه‌شده
1. CRM سرنخ و فعالیت
2. بازار هدف
3. تیپ ارتباطی مشتری
4. سوالات کشف نیاز
5. پیشنهاد ارزش و USP
6. تحلیل رقبا
7. طرح فروش
8. اقدامات اجرایی و سررسید
9. پیگیری‌های سررسید
10. داشبورد فروش حرفه‌ای
11. پنل فارسی برای ثبت و مشاهده

### نصب
1. ابتدا `01_پایگاه_داده/schema.sql` نسخه پایه را اجرا کنید.
2. سپس `01_پایگاه_داده/schema_pdf_sales_extension.sql` را اجرا کنید.
3. Workflowهای پوشه `13_فروش_حرفه‌ای_برگرفته_از_PDF` را در n8n Import کنید.
4. Credential PostgreSQL را برای Nodeهای PostgreSQL انتخاب کنید.
5. `13_پنل_فارسی_فروش_حرفه‌ای/index.html` را باز کنید و `WEBHOOK_BASE` را تنظیم کنید.

### وضعیت
ساختار و JSONها تولید و از نظر JSON syntax اعتبارسنجی شده‌اند؛ اتصال واقعی به محیط شما در این محیط قابل اثبات نیست تا زمانی که Credential PostgreSQL/n8n شما متصل شود.
