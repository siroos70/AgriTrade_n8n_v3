# راهنمای پنل فارسی

## اجرا
فایل `index.html` را در مرورگر باز کنید.

## اتصال به n8n
در بخش «تنظیمات اتصال»:
- نشانی پایه Webhook را وارد کنید.
- مسیر Webhookهای ثبت فروشنده، خریدار، عرضه، تقاضا، معامله و کمیسیون را وارد کنید.
- تنظیمات در مرورگر ذخیره می‌شود.

## نکته امنیتی
این پنل Token یا Credential n8n را داخل کد ذخیره نمی‌کند. برای محیط اینترنتی بهتر است احراز هویت، HTTPS و کنترل دسترسی در لایه سرور/n8n اضافه شود.

## وضعیت نسخه
پنل نسخه ۱ دارای رابط RTL فارسی و فرم‌های واقعی ارسال JSON به Webhook است. جدول‌های نسخه فعلی برای نمایش ساختار MVP با داده نمونه هستند؛ برای نمایش رکوردهای واقعی باید Workflowهای خواندن اطلاعات از PostgreSQL و API/Endpointهای گزارش به آن اضافه شوند.
